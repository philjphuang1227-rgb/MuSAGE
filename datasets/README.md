# Dataset setup

Download SKEMPI v2.0 from the [official database page](https://life.bsc.es/pid/skempi2/database/index). Place the semicolon-separated table at `data/raw/SKEMPI2.csv` and extract the cleaned structures under `data/raw/pdb/`.

Do not add these benchmark files or generated feature caches to this repository. See [DATA_PROVENANCE.md](../docs/DATA_PROVENANCE.md) for source and pretrained-feature details, and [REPRODUCIBILITY.md](../docs/REPRODUCIBILITY.md) for preparation commands.
